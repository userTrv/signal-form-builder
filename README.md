# Signal Form Builder

Dynamic form engine and visual form builder on Angular 22 Signal Forms: a typed JSON schema with conditional logic, cross-field and async validation, computed fields, repeatable groups and wizards, plus TypeScript types generated from the schema.

> Work in progress. The live demo will be at https://usertrv.dev/projects/signal-form-builder/. What remains is listed in [NEXT_STEPS.md](NEXT_STEPS.md).

```bash
pnpm install
pnpm start
pnpm test
pnpm build
```
